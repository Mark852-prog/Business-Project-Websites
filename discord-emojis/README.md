# Discord Emoji Pack — Roleplay Server

104 flat icons in two colours, each 128×128 PNG with a transparent background.

- `orange/` — every icon in one orange tone, `#FF8A48` (taken from the reference set). Files start with `o_`.
- `white/` — the same icons in white. Files start with `w_`.
- `preview-orange.png`, `preview-white.png` — contact sheets of each set.

Discord makes the emoji name from the file name, so `o_gavel.png` becomes `:o_gavel:`.

## Upload
Server Settings → Emoji → **Upload Emoji**. You can select several files at once.
Emoji slots without boosts: 50 static. Level 1: 100. Level 2: 150. Level 3: 250.

Icons are from Font Awesome Free (CC BY 4.0, https://fontawesome.com/license/free).
